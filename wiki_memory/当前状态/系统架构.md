# 系统架构

## 架构概览

系统分为根目录宿主层和独立 p5.js 工程层。宿主由 Vite 提供入口，工程由清单自动发现并挂载到 `#project-host`；工程不共享全局 DOM 或状态。

## 模块关系

| 模块 | 职责 | 依赖 | 入口 |
| --- | --- | --- | --- |
| `index.html` + `src/style.css` | 自适应主题侧栏、工程目录、载入和错误反馈 | 浏览器 DOM、CSS 变量 | `/` |
| `src/main.js` | 清单发现、主题令牌、侧栏状态、URL 状态、destroy/mount 切换 | Vite、工程 manifest | `index.html` |
| `projects/flying-dandelion/` | 鸟群绘制、实时控件、p5 生命周期 | 根目录 p5.js | `project.js` |
| `projects/lotus-pond/` | 荷叶双群落、鼠标锦鲤、碰撞染色和实时控件 | 根目录 p5.js | `project.js` |
| `wiki_memory/` | 项目记忆、lint 和日志索引 | Python 标准库 | `工具/memory_lint.py` |

## 数据流或请求流

页面启动时读取 `?project=<slug>`，宿主从清单选取工程，将其 `theme.surface/ink/accent` 写入宿主 CSS 变量，按 manifest 的 `icon` 键渲染目录标记，更新左侧目录当前项并调用 `mount(container)`。侧栏展开/收起状态通过本地存储恢复。切换或浏览器前进后退时，先调用旧工程的 `destroy()`、清空容器，再挂载新工程；销毁异常会被记录但不会阻断下一个工程，载入异常会清空容器并显示错误层。

## 运行与部署

开发使用 `npm run dev`，默认从 `127.0.0.1:5189` 开始监听；当端口已被占用时，Vite 自动递增到下一个空闲端口，并在终端打印实际地址。也可通过 `npm run dev -- --port 5200` 为某个实例指定端口。构建使用 `npm run build`，预览服务器遵循相同的起始端口和自动递增策略。所有工程共享根目录 `p5` 依赖，Vite 负责打包。
