# 项目概览

## 项目名称

飞鸟实验室：统一的 Vite + p5.js 多工程工作区。

## 项目目标

在一个开发服务器和统一顶栏中运行、切换多个独立 p5.js 作品，同时保持工程之间的 DOM、状态和清理边界。当前包含“飞鸟蒲公英”和“莲花小池”两个可实时调节的生成艺术工程。

## 当前阶段

已完成仓库初始化、多工程宿主协议、工程记忆初始化、第二个真实工程接入和自适应主题顶栏；双向切换、URL 恢复、主题令牌应用与销毁边界已经过桌面浏览器验证。

## 主要用户或使用者

维护和创作 p5.js 生成艺术作品的开发者。

## 重要入口

- `/`：宿主首页。
- `http://127.0.0.1:5189/`：固定端口的宿主首页。
- `http://127.0.0.1:5189/?project=flying-dandelion`：按 URL 恢复当前工程。
- `http://127.0.0.1:5189/?project=lotus-pond`：按 URL 恢复莲花小池工程。
- `npm run dev`、`npm run build`：开发与构建入口。
