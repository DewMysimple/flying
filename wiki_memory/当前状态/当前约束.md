# 当前约束

## 技术约束

- 根目录使用 Vite，工程使用 p5.js；共享根目录依赖，不为每个工程建立独立 `node_modules`。
- 每个工程必须实现 `mount(container)` 和 `destroy()` 边界，并清理自己的 p5 实例、DOM 和事件监听器。
- 工程目录使用 `projects/<slug>/`，由宿主清单自动发现。
- 工程 manifest 提供 `theme.surface`、`theme.ink`、`theme.accent` 语义令牌，并可提供语义 `icon` 键；宿主不得按具体 slug 硬编码主题颜色或图标。
- 开发和预览服务器默认从 `127.0.0.1:5189` 开始监听；端口冲突时允许 Vite 自动递增到空闲端口，并以终端输出的实际端口为准。可通过 CLI 显式指定端口。

## 兼容性约束

- URL 查询参数 `project` 是当前工程的恢复协议，刷新和前进后退都应可恢复。
- 宿主侧栏和飞鸟工程保持现有桌面布局；莲花小池当前以桌面鼠标为目标，本轮不把手机显示优化作为验收条件。
- 莲花小池不提供图片、视频或其他导出功能。
- 杜鹃啼血是桌面横屏叙事作品，不做手机端专项适配、音频、图片或视频导出；全部画面由代码绘制。
- 杜鹃啼血的创作参数使用版本化本地存储保存，播放进度、暂停状态和当前幕不持久化。
- 系统启用减少动态效果时作品应保持可用。
- 工程目录使用无第三方依赖的可访问原生按钮，支持展开/收起、鼠标、Tab、Enter 和 Space；收起后工程标记仍可直接切换。
- 四张教程 JPG 保持原样，作为仓库内不可变参考资料。
- 莲花小池教程视频、最终效果预览和文字稿作为参考资料，不进入前端构建。

## 质量约束

- 每批改动完成后必须先构建、运行记忆 lint，并进行与风险匹配的浏览器检查。
- 不提交 `node_modules/`、`dist/`、密钥、令牌、本地缓存或临时截图。

## 操作边界

- 通过 `origin/main` 管理远程版本；提交后必须推送，不使用强制推送。
- 推送失败时保留本地提交并报告原因。
