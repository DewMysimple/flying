# ADR-005：左侧目录式工程导航

## 背景

顶部下拉切换器在收起状态下只能提供抽象色点，无法快速辨识“飞鸟蒲公英”和“莲花小池”。统一宿主需要一个更接近目录的工程入口，同时保留画布空间和未来多工程扩展能力。

## 选择

- 移除宿主顶部横向切换器，改为固定左侧工程目录。
- 侧栏支持展开和收起；收起后保留窄图标轨道，工程仍可直接点击切换。
- 侧栏展开/收起状态使用本地存储记忆，首次访问默认展开。
- 工程 manifest 可提供语义 `icon` 键。宿主使用统一的线性图标定义渲染；缺失或未知键回退为工程标题首字，不按 slug 判断。
- 侧栏只管理工程切换，作品自身的参数面板和画布逻辑保持独立。

## 理由与影响

目录名称和专属图标同时可见，收起后仍能快速区分工程，且新增工程只需在 manifest 中声明图标键或依赖首字回退。侧栏覆盖画布左侧，不改变 p5 画布尺寸和工程生命周期协议；本轮不新增移动端布局规则。

## 验证方式

使用桌面浏览器检查展开/收起宽度、图标识别、条目切换、URL 恢复、本地存储记忆和旧工程销毁；使用 `npm run build`、memory lint 与 `git diff --check` 验证仓库完整性。来源见 [[日志/2026-09-02-左侧目录式工程导航|左侧目录式工程导航日志]]。
