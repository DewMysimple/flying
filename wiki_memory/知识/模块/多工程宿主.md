# 多工程宿主

## 职责

`src/main.js` 负责通过 `import.meta.glob('../projects/*/project.js')` 构建工程清单、填充左侧工程目录、同步 `?project=<slug>`、应用当前工程主题令牌、管理当前工程的 `destroy()`，并在载入异常时清空挂载容器。销毁异常会被捕获和记录，避免单个工程阻断后续切换。侧栏展开/收起状态使用本地存储记忆。

## 工程接口

每个 `projects/<slug>/project.js` 导出 `manifest`，其中 `mount(container)` 必须返回清理函数。工程可在 manifest 的 `theme` 中提供 `surface`、`ink`、`accent` 三个语义颜色令牌；宿主只消费令牌，不按 slug 分支维护项目颜色。工程专属样式和 DOM 放在自己的目录与容器内。

manifest 可选提供 `icon` 语义键（当前支持 `bird` 和 `lotus`），宿主用统一线性图标渲染收起后的目录标记；未知或缺失的键回退为工程标题首字，不影响新增工程接入。

侧栏使用主题令牌派生背景、边框、悬停态和选中态；展开时显示工程名称，收起时保留主题色标记轨道。工程条目使用原生按钮，避免系统下拉菜单样式差异。已在“飞鸟蒲公英”和“莲花小池”之间完成双向切换验证；切换后只保留当前工程根节点和一个可见主画布。

## 变更位置

- 宿主 UI：`index.html`、`src/style.css`。
- 切换协议：`src/main.js`。
- 作品实现：对应 `projects/<slug>/`。
