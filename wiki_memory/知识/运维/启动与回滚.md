# 启动与回滚

## 启动

安装依赖后运行 `npm run dev`，默认通过 `http://127.0.0.1:5189/` 打开工程；如果该端口被占用，Vite 会自动递增并在终端显示新的地址。生产预览使用 `npm run build` 后的 `npm run preview`，同样允许自动递增。需要固定端口时可运行 `npm run dev -- --port 5200`。

开发服务是独立的 Node/Vite 进程，关闭浏览器标签或终端窗口不一定会结束它。重启前应在运行服务的终端按 `Ctrl+C`；找不到终端时，先用 `Get-NetTCPConnection -LocalPort <端口> -State Listen` 找到监听 PID，再结束确认属于本仓库的进程。

## 恢复

优先查看浏览器错误层和终端构建输出。若新工程载入失败，宿主会清空旧画布并显示错误，不会保留残留工程 DOM。代码恢复使用 Git 提交历史，先定位目标提交，再在确认后回滚或修复；禁止强制推送覆盖远程历史。
