# 启动与回滚

## 启动

安装依赖后运行 `npm run dev`，通过宿主首页或 `/?project=flying-dandelion` 打开工程。生产预览使用 `npm run build` 后的 `npm run preview`。

## 恢复

优先查看浏览器错误层和终端构建输出。若新工程载入失败，宿主会清空旧画布并显示错误，不会保留残留工程 DOM。代码恢复使用 Git 提交历史，先定位目标提交，再在确认后回滚或修复；禁止强制推送覆盖远程历史。
