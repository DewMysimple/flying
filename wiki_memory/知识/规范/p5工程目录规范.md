# p5 工程目录规范

新工程使用 `projects/<slug>/` 目录，并至少包含 `project.js`、`sketch.js` 和工程专属 `style.css`。`project.js` 导出 `{ slug, title, mount }`；`mount(container)` 内创建 p5 实例和工程 DOM，并返回销毁函数。

工程不得写入宿主顶栏，不得依赖其他工程的全局状态，不得使用全局 `document.querySelector` 查找工程控件。需要共享能力时，应先在宿主协议或明确的共享模块中定义边界。

相关模块说明：[[知识/模块/多工程宿主|多工程宿主]]。
