# 本地验证与推送

## 固定顺序

1. 运行 `npm run build`。
2. 运行 `python wiki_memory/工具/memory_lint.py check`。
3. 运行 `python wiki_memory/工具/memory_lint.py index`。
4. 检查 `git diff --check` 与 `git status`，确认忽略项和资料范围正确。
5. 使用 Conventional Commit 提交，并执行 `git push origin main`。

推送失败时保留本地提交并报告原因，不使用强制推送。相关决策：[[决策/ADR-002-git-submit-push|ADR-002]]。
