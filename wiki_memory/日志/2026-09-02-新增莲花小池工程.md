# 新增莲花小池工程

## 目标与结果

- 目标：根据教程视频、文字稿和最终效果预览，在统一宿主中新增第二个真实 p5.js 工程。
- 结果：完成桌面全屏“莲花小池”，包含绿色双群落、鼠标锦鲤、点击碰撞持久染粉和四组实时参数，不包含海报文字、手机专项适配或导出功能。

## 已确认需求

- 构图铺满浏览器窗口，不使用参考视频的竖版海报和文字排版。
- 其余视觉尽量高保真，默认使用双群落结构。
- 锦鲤跟随鼠标路径，点击触发碰撞，粉色状态保持到重置。
- 只面向桌面使用，不做图片、视频或其他导出。

## 实现与修复

- 新增 `projects/lotus-pond/` 清单、p5 实现和工程专属样式，宿主自动发现第二个工程。
- 提供双群落结构、荷叶质感、锦鲤路径和水面色彩参数，以及暂停、重置和重排操作。
- 离屏噪点层通过复用 Canvas 避免调参和缩放时累积隐藏画布。
- 双向切换测试暴露并修复飞鸟工程销毁函数的媒体监听器作用域问题。
- 宿主捕获销毁异常，避免单个工程阻断后续加载。

## 测试摘要

- `npm run build` 通过；保留既有 p5 入口体积提示。
- 桌面 Edge 冒烟确认莲花工程、620 片默认荷叶和一个可见主 Canvas。
- 模拟鼠标点击后约 90 片荷叶染粉，重置后计数归零。
- 参数输入可将荷叶数量实时重建为 700，噪点层没有新增可见 Canvas。
- 莲花与飞鸟双向切换后仅保留目标工程根节点和一个可见主 Canvas，浏览器无运行异常。

- 第二个真实工程已接入，多工程切换协议完成实测。
- 莲花小池是桌面优先、无导出的全屏互动工程。
