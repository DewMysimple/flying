# 2026-09-02｜自适应主题顶栏与切换器

- 时间：2026-09-02（北京时间）
- 类型：`ui`
- 状态：`完成`
- 目标：让统一宿主顶栏根据工程主题令牌自适应，并改善工程切换器的圆角、底色、文字对比和键盘交互。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 工程 manifest 提供 `theme.surface`、`theme.ink`、`theme.accent`，宿主不按 slug 硬编码项目颜色。
- 顶栏保持悬浮窄条，左侧显示当前工程名；正常状态不显示重复的常驻状态。
- 工程切换器改为轻量自绘 listbox，支持鼠标、方向键、Enter、Escape 和点击外部关闭。
- 本轮只调整宿主顶栏和切换器，不改两个工程内部控制面板。

## 检查与操作

- 扩展两个工程 manifest 的主题令牌。
- 重构宿主顶栏结构、工程菜单和主题变量应用逻辑。
- 使用 CSS `color-mix()` 从工程令牌派生透明背景、边框、悬停态和选中态，并提供基础回退。
- 将移动浏览器 `theme-color` 同步为当前工程的 `surface`。

## 文件变更

- `index.html`：动态工程标题、切换按钮和 listbox 菜单。
- `src/main.js`：主题应用、菜单交互、加载状态和当前工程同步。
- `src/style.css`：主题变量驱动的顶栏、菜单、反馈层和焦点态。
- `projects/flying-dandelion/project.js`、`projects/lotus-pond/project.js`：补充主题令牌。
- 工程记忆状态页、宿主知识页和 ADR-004。

## 测试与验证

- `npm run build` 通过；保留既有 p5.js 大入口包体积提示。
- 桌面浏览器验证莲花/飞鸟主题令牌、菜单圆角、键盘上下移动、Escape 关闭、双向切换和 URL 恢复。
- 切换后只保留当前工程根节点；工程自身隐藏纹理层仍属于当前工程资源。
- `memory_lint.py check`、`memory_lint.py index` 和 `git diff --check` 在提交前执行。

## 待确认长期记忆

- 无。

## 问题、结果与下一步

- 结果：宿主不再维护具体工程颜色分支，新增工程只需提供主题令牌即可复用顶栏。
- 遗留问题：p5.js 入口包仍超过 Vite 建议阈值，不影响本轮功能。
- 下一步：继续根据实际工程反馈微调主题令牌和顶栏密度。
