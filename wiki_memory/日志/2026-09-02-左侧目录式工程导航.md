# 2026-09-02｜左侧目录式工程导航

- 时间：2026-09-02（北京时间）
- 类型：`ui`
- 状态：`完成`
- 目标：参考用户提供的展开/收起侧栏，将宿主顶部工程切换器改为可识别的左侧工程目录。

## 已确认的决策

- 桌面端侧栏默认展开，支持收起为窄图标轨道；状态保存到本地存储。
- 工程切换只通过侧栏目录完成，移除宿主顶部横向顶栏和下拉 listbox。
- 侧栏只承载工程目录，两个工程内部参数面板与画布绘制保持不变。
- 工程 manifest 增加可选语义 `icon` 键；飞鸟使用 `bird` 线稿，莲花使用 `lotus` 线稿，其他工程缺失时回退标题首字。

## 文件变更

- `index.html`：替换为品牌区、展开/收起按钮和语义工程目录。
- `src/main.js`：渲染工程图标、维护侧栏状态、本地存储和按钮切换。
- `src/style.css`：实现参考图式宽/窄侧栏、目录激活态、图标标记、焦点态与过渡。
- 两个工程的说明文字/提示卡读取宿主侧栏宽度变量，展开时避开侧栏遮挡；画布尺寸和参数面板不变。
- `projects/flying-dandelion/project.js`、`projects/lotus-pond/project.js`：声明工程语义图标。
- `README.md`、工程记忆状态页、宿主知识页、p5 目录规范和 ADR-005：同步侧栏与图标协议。

## 测试与验证

- `npm run build`：通过；保留既有 p5.js 大入口包体积提示。
- 桌面浏览器：展开宽度 `248px`、收起宽度 `76px`；收起后鸟形和荷花图标可辨识，悬停提供工程名称。
- 桌面浏览器：双向切换、URL 恢复、本地存储刷新记忆通过；切换后只保留当前工程根节点和一个可见主画布。
- `python wiki_memory/工具/memory_lint.py check`、`index` 和 `git diff --check` 在提交前执行。

## 遗留问题
