# 修复收起侧栏高亮溢出

## 问题

收起左侧工程目录后，当前工程的主题色竖向激活标记使用按钮左边缘定位。按钮宽 48px、图标卡片宽 40px，标记从 1px 处开始绘制，因此会露在图标卡片外，形成突兀的“竖条”。

## 修复

- 仅调整收起态 `.project-option::before` 的定位和尺寸。
- 将标记内缩到图标卡片内部，使用 7px 左偏移、2px 宽、16px 高和胶囊圆角。
- 展开态目录行的激活标记、工程切换逻辑和主题令牌协议保持不变。

## 验证

- `npm run build` 通过；仅保留既有 p5 大入口体积提示。
- 变更范围通过 `git diff --check`，未引入新依赖、缓存或导出文件。

## 结果

收起侧栏时高亮线与当前工程图标卡片对齐，不再超出图标边界。
