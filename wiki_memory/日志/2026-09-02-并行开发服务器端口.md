# 2026-09-02｜并行开发服务器端口

- 时间：2026-09-02（北京时间）
- 类型：`operations`
- 状态：`完成`
- 目标：解决旧 Vite 进程仍占用 `5189` 时，新的 `npm run dev` 无法启动的问题，并允许多个开发服务器并行运行。

## 已确认的决策

- 默认监听地址仍为 `127.0.0.1`，默认起始端口仍为 `5189`。
- `server` 与 `preview` 均关闭 `strictPort`；端口冲突时由 Vite 自动递增到空闲端口。
- 可使用 `npm run dev -- --port <端口>` 为并行实例显式指定端口。
- 终端输出的实际 URL 是当前实例地址；浏览器标签或终端窗口关闭不作为服务退出的可靠信号。
- ADR-006 替代 ADR-003 的“固定端口且冲突即失败”方案，保留旧决策用于追溯。

## 文件变更

- `vite.config.js`：加入 `VITE_HOST`、`VITE_PORT` 配置入口，默认 `127.0.0.1:5189`，并允许自动端口递增。
- `README.md`：更新并行启动、端口指定和实际 URL 使用说明。
- `wiki_memory/当前状态/项目概览.md`、`系统架构.md`、`当前约束.md`：同步端口策略。
- `wiki_memory/知识/运维/启动与回滚.md`：补充 Vite 子进程和端口排障说明。
- `wiki_memory/决策/ADR-003-fixed-dev-port.md`：标记为 superseded。
- `wiki_memory/决策/ADR-006-parallel-dev-servers.md`：记录新的并行服务器决策。

## 测试与验证

- 在 `5189` 已被当前仓库 Vite 进程占用的情况下启动第二个实例，Vite 自动选择 `5190` 并正常启动。
- 访问 `http://127.0.0.1:5190/?project=lotus-pond` 返回 HTTP 200，宿主侧栏标记存在。
- 使用 `npm run dev -- --host 127.0.0.1 --port 5201` 启动显式端口实例，访问 `?project=flying-dandelion` 返回 HTTP 200。
- 测试实例已停止；原有 `5189` 实例未被修改。
- 交付前执行 `npm run build`、memory lint、`git diff --check`。

## 遗留问题

- 不同端口上的实例都可能属于同一或不同工作区；启动后必须以终端打印的路径和 URL 判断实例归属。
