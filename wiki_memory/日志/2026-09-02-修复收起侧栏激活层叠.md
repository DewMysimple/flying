# 修复收起侧栏激活层叠

## 问题

第一次修复将激活竖线从按钮左边缘内缩，但竖线仍由外层 `.project-option::before` 绘制。内层 `.project-option-mark` 的背景覆盖了竖线，造成竖线只露出一部分；同时外层按钮激活背景与内层图标卡片叠加，出现多余的圆角底。

## 修复

- 收起态隐藏外层按钮的激活伪元素。
- 收起态取消工程按钮自身的 hover/active 背景，让图标卡片成为唯一的激活表面。
- 在 `.project-option-mark` 内新增主题色激活伪元素，使用相对定位和更高的绘制层级，保证竖线完整显示且不越过图标卡片边界。
- 展开态的目录行背景和左侧激活标记保持原有行为。

## 验证

- `npm run build` 通过；仅保留既有 p5 大入口体积提示。
- 将在提交前运行记忆 lint、索引和 `git diff --check`。

## 结果

紧凑侧栏每个工程只显示一个图标卡片；当前项的主题色竖线完整位于卡片内部，不再出现外层冗余背景或半截标记。
